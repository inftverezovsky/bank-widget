# Bank Widget

Учебный проект для работы с банковскими операциями.

## Возможности

В проекте реализованы функции для:

- маскировки номера карты и счета;
- форматирования даты;
- фильтрации операций по статусу;
- сортировки операций по дате;
- логирования вызовов функций, результатов и ошибок в консоль или файл.

## Установка

Требуется Python 3.12 или новее в пределах версии 3.x.

```bash
git clone https://github.com/inftverezovsky/bank-widget.git
cd bank-widget
git checkout feature/homework_decorators
poetry install --with dev,lint
```

Команды ниже выполняются в виртуальном окружении проекта. Без его активации
добавьте перед командой `poetry run`, например `poetry run pytest`.

## Декоратор log

Модуль `src/decorators.py` содержит декоратор `log(filename=None)` для
синхронных функций. На каждый вызов записываются три сообщения:

1. `start` — имя функции, время вызова в UTC, позиционные и именованные аргументы;
2. `ok` и результат либо `error` с типом, текстом исключения и входными параметрами;
3. `end` — имя функции и время завершения в UTC, в том числе при исключении.

Без `filename`, а также при `filename=None`, сообщения выводятся в консоль:

```python
from src.decorators import log


@log()
def add_numbers(left: int, right: int) -> int:
    """Вернуть сумму двух чисел."""
    return left + right


result = add_numbers(1, 2)
assert result == 3
```

Пример вывода; временные метки зависят от момента вызова:

```text
add_numbers start. Time: 2026-09-15T10:00:00+00:00. Inputs: (1, 2), {}
add_numbers ok. Result: 3
add_numbers end. Time: 2026-09-15T10:00:00+00:00
```

Чтобы записывать сообщения в файл, передайте `filename`:

```python
from src.decorators import log


@log(filename="mylog.txt")
def divide(dividend: float, divisor: float) -> float:
    """Разделить одно число на другое."""
    return dividend / divisor


divide(6, 2)

try:
    divide(1, divisor=0)
except ZeroDivisionError:
    print("Деление на ноль: ошибка записана в mylog.txt")
```

Файл создается при первом вызове, сообщения дописываются в конец в UTF-8.
Каталог для файла должен существовать. Для ошибочного вызова в примере
записывается строка:

```text
divide error: ZeroDivisionError. Inputs: (1,), {'divisor': 0}. Error: 'division by zero'
```

После логирования исключение передается вызывающему коду без замены и подавления.
Декоратор возвращает исходный результат, сохраняет имя, docstring, аннотации
и сигнатуру функции через `functools.wraps`, `ParamSpec` и `TypeVar`.

Аргументы и результаты записываются без маскировки. Не передавайте в лог пароли,
токены или полные банковские реквизиты. К существующим функциям маскировки
декоратор автоматически не применяется. Ошибки записи файла также не подавляются.

## Тестирование

Для тестирования используется `pytest`.

Запуск всех тестов:

```bash
pytest
```

Тесты разделены по модулям:

- `tests/test_masks.py` — функции из `masks.py`;
- `tests/test_widget.py` — функции из `widget.py`;
- `tests/test_processing.py` — функции из `processing.py`;
- `tests/test_decorators.py` — декоратор `log`;
- `tests/conftest.py` — общие фикстуры с тестовыми данными.

В тестах используются фикстуры и параметризация `pytest.mark.parametrize`.
Вывод в консоль проверяется через `capsys`, файлы создаются во временной
директории `tmp_path`. Для декоратора проверяются оба назначения логов,
успех и исключения, передача аргументов, временные метки, дозапись,
кириллица, сохранение результата и метаданных, независимость функций.

Покрытие строк и ветвлений запускается автоматически вместе с `pytest`.
Минимально допустимое покрытие в настройках проекта — 80%.

Результат контрольного запуска:

```text
68 passed
src/decorators.py: 27 statements, 0 missed, 2 branches, 0 partial
TOTAL: 63 statements, 0 missed, 16 branches, 0 partial
Coverage: 100%
```

В репозитории сохранена HTML-сводка контрольного запуска: `htmlcov/index.html`.
Команда `pytest` пересоздает в этой папке подробный HTML-отчет `coverage.py`
с построчным покрытием. Откройте `htmlcov/index.html` в браузере.

## Проверка качества кода

```bash
flake8 src tests
mypy src tests
isort --check-only src tests
```

Эти же проверки вместе с `pytest` выполняются автоматически в GitHub Actions
при открытии или обновлении pull request в `develop`.

## Именование

Имена переменных и функций записаны в `snake_case`. Все реализованные функции
имеют docstring и аннотации типов. Однобуквенные пользовательские имена
переменных не используются.
